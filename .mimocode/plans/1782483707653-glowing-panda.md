## CSS Animation Definitions (in `resources/css/app.css`)

```css
/* Custom keyframe animations for Tailwind v4 */
@keyframes slideUp {
  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}

@keyframes slideDown {
  from { opacity: 0; transform: translateY(-10px); }
  to { opacity: 1; transform: translateY(0); }
}

@keyframes fadeIn {
  from { opacity: 0; }
  to { opacity: 1; }
}

@keyframes float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-10px); }
}

@keyframes scaleIn {
  from { opacity: 0; transform: scale(0.95); }
  to { opacity: 1; transform: scale(1); }
}
```

## Tailwind v4 Patterns Used

| Pattern | Usage |
|---------|-------|
| `transition-all duration-200 ease-out` | Buttons, cards, sidebar links |
| `hover:-translate-y-0.5` | Button/card lift |
| `active:scale-95` | Button press feedback |
| `hover:shadow-lg` / `hover:shadow-md` | Elevation change |
| `transition-colors duration-150` | Table rows, dropdown items |
| `animate-pulse` | Status badges, live indicators |
| `motion-safe:` prefix | All transform-based animations |
| `motion-safe:animate-[...]` | Entry animations (slideUp, fadeIn, scaleIn) |
| `focus-visible:ring-2` | Keyboard accessibility |

---

## Accessible Motion Strategy

All positional/structural animations wrapped with `motion-safe:`:
- `motion-safe:animate-[slideUp_0.5s_ease-out]`
- `motion-safe:animate-[slideDown_0.2s_ease-out]`
- `motion-safe:animate-[scaleIn_0.3s_ease-out]`
- `motion-safe:animate-[float_6s_ease-in-out_infinite]`
- Non-transform transitions (color, shadow) don't need `motion-safe:` — they're safe for all users

## Scope Boundaries

- **NOT modifying**: Structural layout, flex directions, grid spans, element nesting
- **NOT adding**: New JavaScript, new CSS files, new components
- **Preserving**: All existing functionality, dark mode support, responsive behavior
- **Only layering**: Transition/animation utility classes onto existing DOM nodes
