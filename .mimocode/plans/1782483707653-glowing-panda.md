# Sidebar 3-Mode Toggle Implementation Plan

## Project Context
Laravel + Tailwind CSS v4 app using Mazer Bootstrap template. The user wants a 3-mode toggle button group in the sidebar to switch between:
1. **Full Mode** — Current default: icons + full text labels
2. **Focus Mode** — Collapsed icon-only sidebar (saves horizontal space)
3. **Custom Mode** — Hides advanced menus (Administration, Login Logs, Settings), keeps core links only

**Tech Stack:** Laravel Blade, Tailwind CSS v4, Mazer Bootstrap template

---

## Files to Modify

### 1. `resources/views/partials/sidebar.blade.php`

- Add a 3-button segmented toggle group below the "E-Faktur Penjualan" header
- Add `data-mode` attribute to `.sidebar-wrapper` for state management
- Wrap advanced menu items with `data-advanced` attribute for Custom Mode hiding

### 2. `resources/css/app.css`
**Add sidebar mode CSS:**

### B. State Management (CSS Classes)
Apply to `.sidebar-wrapper`:
- `[data-mode="full"]` — Default state (w-64 / 256px)
- `[data-mode="focus"]` — Icon-only (w-20 / 80px), hide text labels
- `[data-mode="custom"]` — Full width but fade out `[data-advanced]` items

### D. JavaScript State Handler
```javascript
// Mode toggle logic
(function() {
    const wrapper = document.querySelector('.sidebar-wrapper');
    const buttons = document.querySelectorAll('[data-mode]');
    const STORAGE_KEY = 'sidebar-mode';
    
    // Load saved mode or default to 'full'
    const savedMode = localStorage.getItem(STORAGE_KEY) || 'full';
    setMode(savedMode);
    
    buttons.forEach(btn => {
        btn.addEventListener('click', () => {
            const mode = btn.dataset.mode;
            setMode(mode);
            localStorage.setItem(STORAGE_KEY, mode);
        });
    });
    
    function setMode(mode) {
        wrapper.dataset.mode = mode;
        buttons.forEach(b => {
            b.classList.toggle('active', b.dataset.mode === mode);
        });
    }
})();
```
