# Plan: Add "Saldo" Button to Chart of Accounts List

## Goal
Add a "Saldo" button next to "Detail" in the Chart of Accounts index page that links to the General Ledger detail page for that account.

## Changes Required

### 1. View: `resources\views\chart_of_accounts\index.blade.php`

**In the "Aksi" (Actions) column, add a "Saldo" button:**

Current:
```php
<td>
    <a class="btn btn-sm btn-outline-primary" href="{{ route('chart-of-accounts.show', $account) }}">Detail</a>
    @if($isManager)
        <a class="btn btn-sm btn-outline-secondary" href="{{ route('chart-of-accounts.edit', $account) }}">Edit</a>
    @endif
</td>
```

Change to:
```php
<td>
    <a class="btn btn-sm btn-outline-primary" href="{{ route('chart-of-accounts.show', $account) }}">Detail</a>
    <a class="btn btn-sm btn-outline-success" href="{{ route('ledger.show', $account->account_no_new) }}">Saldo</a>
    @if($isManager)
        <a class="btn btn-sm btn-outline-secondary" href="{{ route('chart-of-accounts.edit', $account) }}">Edit</a>
    @endif
</td>
```
