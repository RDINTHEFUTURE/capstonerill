# Plan: Secure Database Password

## Goal
Remove the hardcoded DB password from committed files and make it available only via a Windows environment variable on your machine.

## How it works
Laravel uses `env('DB_PASSWORD')` to read the password. If the env var is set at the OS level, Laravel uses it. If not set, the app can't connect to the database — which is exactly the behavior you want.

---

## Steps

### 1. Remove password from `README.md`
**File:** `README.md` (line 32)

Replace the hardcoded password with a placeholder:
```
DB_PASSWORD=your_password_here
```

### 2. Delete `.env_override_vars.txt` from git tracking
```bash
git rm --cached .env_override_vars.txt
```
Then add it to `.gitignore`.

### 3. Delete `.env.bak` from git tracking
```bash
git rm --cached .env.bak
```
Then add it to `.gitignore`.

### 4. Update `.gitignore`
Add these lines:
```
.env.bak
.env_override_vars.txt
.env.local
.env.*.local
```

### 5. Remove `DB_PASSWORD` from `.env`
Remove line 15 (`DB_PASSWORD=4321`) from `.env` so the app relies entirely on the OS environment variable.

### 6. Set Windows environment variable
Run this in PowerShell (as Administrator for system-wide, or without for user-only):
```powershell
[System.Environment]::SetEnvironmentVariable("DB_PASSWORD", "your_new_strong_password", "User")
```

### 7. Restart your terminal / PHP server
Environment variables are loaded at process start. Restart your terminal and `php artisan serve` for the new var to take effect.

---

## Verification
1. After step 6, open a **new** terminal and run:
   ```powershell
   echo $env:DB_PASSWORD
   ```
   It should print your password.

2. Run `php artisan migrate` — it should connect successfully.

3. Check that `.env_override_vars.txt` and `.env.bak` no longer appear in `git status` as tracked.

4. Verify `README.md` no longer contains the real password.

---

## Files modified
- `README.md` — remove hardcoded password
- `.env_override_vars.txt` — untrack from git
- `.env.bak` — untrack from git
- `.gitignore` — add new exclusion patterns
- `.env` — remove `DB_PASSWORD` line

## Security note
The `.env` file is already gitignored and safe to keep locally. But removing `DB_PASSWORD` from it means even a leaked `.env` won't contain the password — it only lives in your Windows environment variable.
