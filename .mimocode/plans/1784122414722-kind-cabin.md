# Rencana: Batasi Download PDF Invoice yang Belum Disetujui

## Tujuan
Membatasi agar hanya invoice dengan status `approved` yang bisa diunduh PDF-nya. Invoice `pending_review` dan `revision_needed` tidak boleh bisa download/preview PDF.

## File yang Perlu Diubah

### 1. `app/Http/Controllers/InvoicePdfController.php`
Tambah pengecekan approval status di kedua method:

**`preview()` (line 9-16):**
```php
public function preview(Invoice $invoice)
{
    if (!$invoice->isApproved()) {
        abort(403, 'Hanya invoice yang sudah disetujui yang bisa di-preview.');
    }
    $invoice->loadMissing('items.chartOfAccount');
    return view('invoices.preview', [
        'invoice' => $invoice,
    ]);
}
```

**`show()` (line 23-35):**
```php
public function show(Invoice $invoice)
{
    if (!$invoice->isApproved()) {
        abort(403, 'Hanya invoice yang sudah disetujui yang bisa diunduh.');
    }
    $invoice->loadMissing('items.chartOfAccount');
    // ... existing PDF generation code
}
```

### 2. `resources/views/invoices/show.blade.php`
Sembunyikan tombol "Preview Faktur" jika invoice belum approved:

**Line 28** — ubah dari:
```blade
<a class="btn btn-primary ..." href="{{ route('invoices.preview', $invoice) }}">Preview Faktur</a>
```
menjadi:
```blade
@if($invoice->isApproved())
    <a class="btn btn-primary ..." href="{{ route('invoices.preview', $invoice) }}">Preview Faktur</a>
@endif
```

### 3. `resources/views/invoices/review.blade.php`
Sembunyikan tombol "Download PDF" di halaman review (karena invoice di halaman review belum tentu approved):

**Line 137-140** — tambahkan kondisi:
```blade
@if($invoice->isApproved())
    <a class="btn btn-outline-secondary w-100" href="{{ route('invoices.pdf', $invoice) }}">
        <i class="bi bi-download"></i> Download PDF
    </a>
@endif
```

### 4. `resources/views/invoices/preview.blade.php`
Tombol "Unduh PDF" di halaman preview sudah di-cover karena halaman preview sendiri tidak bisa diakses jika invoice belum approved.

## Verification
1. Buat invoice baru (status otomatis `pending_review`)
2. Coba akses halaman preview (`/invoices/{id}/preview`) — harusnya muncul error 403
3. Coba akses route download PDF (`/invoices/{id}/pdf`) — harusnya muncul error 403
4. Review dan approve invoice
5. Coba akses preview dan download lagi — harusnya berhasil
6. Check tombol UI: tombol "Preview Faktur" harus hilang untuk invoice yang belum disetujui
