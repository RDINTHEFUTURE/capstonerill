# Convenience Features: Excel Export, Sales Reports, and More

## Goal
Add Excel export, sales reports, and convenience features to make the app more practical.

## Features to Implement

### 1. Sales Report
- New page at `/reports/sales` with date range filter
- Show: total revenue, total invoices, paid/unpaid breakdown
- Chart of revenue by month (optional)
- Filter by: date range, status, seller/buyer

### 2. Excel Export
- Export invoices list to Excel (.xlsx)
- Export ledger to Excel
- Export trial balance to Excel
- Use `maatwebsite/excel` package

### 3. Invoice Auto-Numbering
- Auto-generate invoice numbers (e.g., INV-2026-0001)
- Configurable prefix and format

### 4. Quick Actions
- Duplicate invoice (create new from existing)
- Bulk mark as paid

## Packages Required
- `maatwebsite/excel` for Excel export
