# Fix: Route model binding not resolving — approve/reject INSERT instead of UPDATE

## Problem
Controller parameter `$request` doesn't match route parameter `{passwordResetRequest}`, so Laravel creates a new empty model instead of finding the existing one. `save()` then tries INSERT (fails because `user_id` has no default).

## Fix
**File:** `app\Http\Controllers\Admin\PasswordResetController.php`
- Rename parameter from `$request` to `$passwordResetRequest` in both `approve()` and `reject()` methods to match route parameter name

## Verification
- Click "Setujui" → status changes to "Disetujui" (no error)
- Click "Tolak" → status changes to "Ditolak" (no error)
