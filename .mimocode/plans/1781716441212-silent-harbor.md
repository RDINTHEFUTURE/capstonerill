## Flow Summary

### Authentication
1. **Login**: User enters email/password → `Auth::attempt()` → log to `login_logs` → redirect to dashboard
2. **Register**: POST /register → create user
3. **Forgot Password**: Enter email → create `PasswordResetRequest` (status=pending) → redirect to status page
4. **Password Reset**: Admin approves → user sets new password via token link → request deleted
5. **Logout**: `Auth::logout()` → invalidate session → regenerate CSRF → redirect to login

### Core: Invoices
- **Create**: Fill seller/buyer info + items → compute subtotals → build QR payload (base64 JSON) → save invoice + items → post journal entries → log activity
- **Edit**: Same as create but updates existing → refresh items → re-post journal
- **Delete**: Reverse journal entries → delete invoice → log activity
- **Status**: Mark paid/unpaid
- **Duplicate**: Copy invoice with new auto-generated nomor
- **PDF**: Generate via dompdf → download
- **QR**: Return QR image (uploaded DJP image or generated from PDF URL)
- **Bulk**: Batch mark paid/unpaid/delete

### Accounting
- **Chart of Accounts**: CRUD for account hierarchy
- **General Ledger**: View balances + per-account journal entries

### Reporting
- Sales report, Export CSV (invoices, ledger, trial balance), Import CSV (invoices, COA)

### Admin
- View/review password reset requests (approve/reject)

### Activity
- All CRUD operations log to `activity_logs`
- Login attempts log to `login_logs`
